# 功能状态与已知限制

本页只记录当前代码能做、不能做和尚未验证的部分，便于接手时快速判断。

## 已实现

- **登录**：本机 Chrome/Edge 一键登录、手动 Cookie、二维码；二维码可能被平台风控拦截。
- **歌单扫描**：读取全部歌单，可勾选「我喜欢的音乐」；缺口按播放地址终审。
- **云盘判重**：songId 精确匹配与标题模糊匹配；疑似已有时在原因栏标注。
- **歌单补歌**：先勾选缺口，再后台匹配；匹配页每页 10 首，逐首选择版本和音质。
- **搜索补歌**：关键词直搜音源，支持分页、多选、逐首音质；慢音源后台合并。
- **可插拔音源**：仓库自带酷我、咪咕适配器；支持多目录叠加、单源覆盖、按注册名启停与优先级排序。
- **后台队列**：任务持久化、断点续跑、字节级进度、失败重试、上传后校验。
- **任务栏**：所有页面常驻显示匹配、队列、成功/失败与最近结果。
- **自检与日志**：`doctor`、`/api/history`、`data/logs/music_refill.log`。

## 已知限制

| 项目 | 当前情况 | 影响 | 可行方向 |
|---|---|---|---|
| 秒传 | 有 `upload/check` 分支，但外部歌曲通常拿不到曲库 MD5 | 多数情况仍需下载后上传 | 仅作为兜底，不宜宣传“秒传优先” |
| 未匹配文件可播性 | 未匹配曲库时只能验证文件已进云盘 | 不能自动证明客户端可播放 | 人工抽查，或接入云盘播放校验 |
| 音质真实性 | 按扩展名和音源声明归类，未解析真实码率 | “320/128/FLAC”不是严格保证 | 用 mutagen/ffprobe 读码率并校验升频 |
| 单版本多音质 | 当前音源通常每个结果只解析出一种音质 | 音质下拉有时只有一项 | 需要音源提供多音质列表或多次解析 |
| 匹配结果持久化 | 匹配与搜索会话只在内存 | 服务重启后需重新扫描/搜索 | 如需长期保留可新增会话表 |
| 进度推送 | 前端按 1 秒轮询 | 功能正常，请求数偏多 | 有需要时改 SSE/WebSocket |
| 歌单写入 | 不支持把云盘歌曲加入歌单 | 补完歌仍需手动收藏 | 可新增“加入歌单”接口 |
| 删除云盘 | 不支持 | 错传需在客户端删除 | 风险较高，默认不提供 |
| 多账号 | 单 Cookie、单会话 | 无法并行隔离多个账号 | 保持单账号模式 |
| 分发 | 无安装包 | 需要 Python 3.11+ | 如需分发可用 PyInstaller |
| 快速补歌旧接口 | `/api/quick-add` 保留兼容，当前前端未使用 | 存在两条入口 | 确认无外部依赖后可删除 |
| 搜索候选曲库 ID | 音源结果不一定能对应网易曲库 | 云盘里可能显示为私有版本 | 依赖元数据匹配，无法保证 |
| 冷门歌慢源 | 咪咕个别候选解析较慢 | 首批结果可能暂时不含该源 | 调大 `source_search_first_batch_s` |
| 音源失效 | 上游接口随时可能变更 | 对应源不可用，其它源继续工作 | 修改单个适配器文件后调用 `/api/sources/reload` |

## 体积与运行数据

- 登录复用本机浏览器，不下载 Playwright 内核。
- `.venv/`、`data/`、`config.toml` 不进入版本库。
- `data/` 可能包含 Cookie、SQLite、日志、下载缓存与报告，不应公开分发。
- musicdl 的中间产物定向到 `data/musicdl/`。
